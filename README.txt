STUDENT ATTENDANCE MANAGEMENT SYSTEM

Technology:
- Python
- Flask
- HTML/CSS
- MySQL
- VS Code

Demo accounts:
Admin   -> admin / admin123
Faculty -> faculty / faculty123
Student -> student1 / student123

Important:
1. Start MySQL before running the Flask app.
2. Import schema.sql into MySQL.
3. If MySQL root has a password, edit DB_CONFIG in app.py.
4. Install requirements:
   pip install -r requirements.txt
5. Run:
   python app.py
6. Open:
   http://127.0.0.1:5000
